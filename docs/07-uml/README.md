## Modeling Scope

The UML package focuses on the main Craft BD workflows:

- Authentication
- Product discovery
- Artisan product management
- Standard commerce
- Structured custom order
- Reviews
- Administration
- Optional verification support

## Research Boundary

The Structured Custom Order workflow remains provisional pending primary Customer and Artisan validation.

Its UML representation describes the current intended system behavior and does not represent completed user validation.
